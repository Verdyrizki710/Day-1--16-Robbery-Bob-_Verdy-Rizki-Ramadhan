## Deskripsi Repository

Repository ini berisi dokumentasi kegiatan workshop **"From AI to GitHub: Building with AI, Managing Change with GitHub"** pada Day 1. Isinya mencakup rangkuman materi, catatan penting, serta langkah-langkah praktik yang dipelajari selama workshop.

## Tujuan Repository

- Mendokumentasikan materi dan catatan workshop secara rapi dan terstruktur.
- Menjadi bahan referensi pribadi untuk mengulang materi di kemudian hari.
- Menjadi bukti penyelesaian tugas workshop sekaligus latihan menggunakan Git dan GitHub.

## Tentang Workshop

Workshop ini dibawakan oleh Nugi Farhan (Senior Product Designer) dan membahas dua topik utama:

1. **Membuat dan mengembangkan** produk dengan bantuan AI (prompt engineering).
2. **Manajemen perubahan dan kolaborasi** menggunakan Git dan GitHub (version control).

Sebagai latihan, peserta membuat aplikasi sederhana **Student Task Planner** dengan bantuan AI, lalu mengelola perubahannya dengan Git dan GitHub.
